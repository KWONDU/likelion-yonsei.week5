# 🛍️ Mini Shopping Mall — Complete (발표자용)

Vercel 배포용. 쇼케이스(전후 비교) + 쇼핑몰 데모.

## 페이지 구조

| URL | 설명 |
|-----|------|
| `/showcase` | 쇼케이스 홈 (4개 섹션 + 데모 링크) |
| `/showcase/typescript` | TS 전후 비교 |
| `/showcase/tailwind` | Tailwind 전후 비교 |
| `/showcase/router` | Router 전후 비교 |
| `/showcase/context` | Context 전후 비교 |
| `/shop` | 완성된 쇼핑몰 데모 |
| `/shop/products` | 상품 목록 |
| `/shop/products/:id` | 상품 상세 |
| `/shop/cart` | 장바구니 |

## 시작하기

```bash
npm install
npm run dev
```

## 배포

GitHub push → Vercel import → 자동 배포
